## Installation and limits

Extract the complete checksummed Windows x64 ZIP, retain its notices and launch TacticalAiDesigner.exe. The individual Desktop icon uses the tested self-contained .NET 10.0.15 application; no SDK or Unity installation is required.

Projects live outside the installation in an owner-local plaintext profile. Protect exports and use authorized inputs. Separate synthetic profiles were used for validation; ordinary user data was not opened.

This is a fictional game and deterministic simulation. Generated balance results describe the chosen seeds, action cap and agent policy; they are not predictions of player behavior.

The Unity bridge is a compiled contract check. Unity Editor, PlayMode, multiplayer, live control and a signed Windows installer were not validated. The local profile is not encrypted multiuser storage.

Individual shortcut targets were read-back verified. Actual installed-executable acceptance is separate from ordinary default-profile shortcut activation, which was not independently exercised. Only synthetic inputs and isolated outputs were used; normal user data and Docker were not opened or changed. This documentation commit requires its own original hosted checks and processed security analyses; prior runtime evidence does not certify later source changes.
